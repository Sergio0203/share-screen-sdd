# Compartilhar tela

App web para compartilhar a tela entre amigos. Crie uma sala com um clique, sem cadastro, e mande o
link para quem você quiser.

## Pré-requisitos

- Node.js 22 ou mais recente

## Como rodar

```bash
npm install
npm start          # http://localhost:3000 (mude a porta com PORT=4000 npm start)
```

## Desenvolvimento

```bash
npm test             # testes unitários e de integração
npm run format       # formata o código com Prettier
npm run format:check # verifica a formatação
```

As especificações de cada funcionalidade ficam em `specs/`, e os princípios do projeto em
`.specify/memory/constitution.md`.
